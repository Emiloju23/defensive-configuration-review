scope and Authorization Statement
Scope
This defensive configuration review was performed on a local Ubuntu virtual machine used for authorized cybersecurity learning and practice.

The review covered:

Password policy
Access control
Running services
Firewall configuration
SSH configuration
System patching and updates
System logging
Backup configuration
Basic system information
Authorization

The system reviewed was a local virtual machine under my control and used for educational purposes.

No unauthorized systems were scanned, accessed, tested, or modified during this project.

All security checks were limited to the authorized local Ubuntu virtual machine.

Evidence Handling

Evidence was collected from the authorized system and reviewed for sensitive information. Passwords, authentication credentials, tokens, and other secrets were not intentionally included in the submitted evidence.
